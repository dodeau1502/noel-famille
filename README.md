# Liste de Noël famille

Une page web où une personne publie ses idées de cadeaux et où ses proches choisissent ce qu'ils offrent, sans que
la personne voie ce qui est pris.

- Le site est dans `site/` et se publie tout seul sur GitHub Pages à chaque modification de `main`.
- Les données vivent dans Supabase (voir `supabase/schema.sql`).
- Le projet est prévu pour être modifié par une IA : lire `CLAUDE.md`.

Les liens d'accès ont la forme `https://<adresse du site>/#c=<code>`. Les codes ne sont pas dans ce dépôt.
